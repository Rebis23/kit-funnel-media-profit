# Kit Funnel · il metodo Media Profit

**[mediaprofit.it](https://mediaprofit.it) · [youtube.com/@mediaprofit](https://www.youtube.com/@mediaprofit)**

Il tuo funnel con Claude: tu racconti il progetto a voce, Claude scrive la pagina, la collega ai tuoi contatti e la mette online sul tuo dominio.

## Come si parte

1. In alto a destra premi **Use this template › Create a new repository**. Nome: ad esempio `funnel-tuonome`. Scegli **Private**. Premi **Create repository**.
2. Apri l'app Claude sul computer, scheda **Code**, e scrivi:
   > Scarica il mio repository GitHub funnel-tuonome e crea il mio funnel.
3. Da lì Claude ti guida un passo alla volta: testi, pagina, contatti, dominio.

Non hai un account GitHub o preferisci partire senza? Scarica questo repository (**Code › Download ZIP**), apri la cartella nella scheda Code di Claude e scrivi «Crea il mio funnel». Claude crea il repository per te quando lo metti online.

## Cosa c'è dentro

| | |
|---|---|
| `.claude/skills/crea-funnel/` | La skill: il metodo Media Profit per testi, pagina, contatti e pubblicazione |
| `site/` | La pagina che va online (la scrive Claude) |
| `functions/api/lead.js` | Riceve i contatti e li manda al tuo foglio Google o al tuo CRM |
| `CLAUDE.md` | Le regole che Claude segue in questo progetto |

La pagina va online con **Cloudflare Pages** (gratis), collegata a questo repository: ogni modifica che Claude salva qui è online in un minuto.
